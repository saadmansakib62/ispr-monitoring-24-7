# ISPR News Monitoring System

24/7 Live Electronic & Print Media Harvester and Multi-Sector Intelligence Report Generator.

## Repository Files Included
- `.gitignore` — Git exclusion rules for Python & local environments
- `DEPLOY_TO_RENDER.md` — Deployment guide for Render.com, Netlify, and GitHub Pages
- `README.md` — Project overview and documentation
- `SOURCE_CATALOGUE.md` — Catalogue of 42+ monitored domestic, regional, and international media feeds
- `START_HERE.txt` — Quick-start instructions for Windows, macOS, Linux, and Web
- `app.py` — Flask backend server & RSS proxy (`/api/rss`, `/api/state`, `/api/health`)
- `index.html` — Complete military-grade Command & Control web application
- `render.yaml` — Render.com Blueprint infrastructure configuration
- `requirements.txt` — Python backend dependencies (`Flask`, `gunicorn`, `requests`, `feedparser`, `flask-cors`)
- `run_mac_linux.sh` — One-click macOS / Linux startup script
- `run_windows.bat` — One-click Windows startup launcher
